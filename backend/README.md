# IT Ticket & Incident Management System

A simple internal tool where employees can raise IT support tickets and track status.

## Current Features
- Create a ticket
- View tickets

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js + Express
- Planned DevOps: GitHub, Jenkins, Docker, Kubernetes, Terraform, Ansible, Prometheus, Grafana
- Hosting: AWS EC2 (Linux)

## Run Locally
### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm run dev

## Git Workflow
- main = stable release branch
- dev = active development branch
- feature/* = new features (merge via Pull Request into dev)
